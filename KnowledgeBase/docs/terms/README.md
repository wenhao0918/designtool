# 机械术语(Terms)

> 机械设计术语知识域:术语定义、几何语义、建模指导、同义词。

## 数据源说明

| 数据 | 位置 | 访问方式 |
|---|---|---|
| 术语主库(生产数据) | Anvil mech_terms 表(经 `/api/terms`) | 检索域 `mechterms` 实时代理,不入本目录 |
| 术语体系文档 | 本目录 | 分类说明/种子文档/术语国标 |

## 术语分类(对应主库字段)

每个术语词条包含:
- **definition** — 专业定义(是什么)
- **geometry** — 几何语义(对应什么几何特征)
- **modeling** — 建模指导(用当前原语体系如何建)
- **aliases** — 同义词(中/英,检索自动解析)

核心术语族:
| 族 | 词条示例 |
|---|---|
| 孔类 | 通孔(盲孔)、贯穿孔、沉头孔、孔位 |
| 台类 | 凸台、搭子、boss |
| 轴类 | 轴段、台阶轴、退刀槽、砂轮越程槽 |
| 板类 | 底板、法兰、筋板 |
| 壳类 | 空心球、壳体、壁厚 |
