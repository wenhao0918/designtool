# 标准件(Parts)

> 标准件知识域:紧固件、轴承、密封件、操作件等国标 + 选型资料。

## 数据源说明

| 数据 | 位置 | 访问方式 |
|---|---|---|
| 标准件库(生产数据) | mn-material 服务(经 Anvil `/api/material/*`) | 检索域 `materials` 实时代理,不入本目录 |
| 标准件国标(画法/选用) | 本目录 | 同 gbstd 模式:每标准一目录(full.md + meta.json) |
