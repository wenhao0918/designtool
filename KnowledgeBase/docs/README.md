# KnowledgeBase 文档资产 — 资料整理工作区

> 定位:**人在这里整理资料,整理好的直接添加到 RAGFlow 知识库**。
> 数字资产本体 = RAGFlow 里的知识库与知识图谱;本目录是供稿前的工作区
> (git 管理、协作整理、留档溯源),kbservice 不依赖此目录。

## 工作流

```
docs/ 整理(替代/校对)
  ↓ 内容定稿
RAGFlow GUI 上传/替换(:1800)
  ↓ 解析(向量切块 / GraphRAG 抽实体)
RAGFlow 知识库(dataset"工程图纸国标" 等)= 数字资产
  ↓ 查询
kbservice 统一 API(8101):gbstd / mechterms / materials
```

## 目录(按知识域)

| 目录 | 域 | 内容 |
|---|---|---|
| `gbstd/` | 工程图纸国标 | 39 项标准清单(README)+ 已整理内容;原文到位后整文件替换再上传 RAGFlow |
| `parts/` | 标准件 | 紧固件/轴承等国标画法与选用(待整理) |
| `terms/` | 机械术语 | 术语体系文档(主库在 Anvil,此处整理分类/种子) |

## 整理规范(供 RAGFlow 切块友好)

- 每个标准一个 `GB_T4458.4-2003/` 目录,内放 `full.md`(完整内容一个文件)
- 内容以条款为单位,每条以 `【GB/T 4458.4-2003 · 条款号 标题】` 行起始
  ——检索命中的 chunk 自带标准号可溯源
- 非原文内容标注 `(替代内容,待原文核对)`;原文到位后整文件替换
- 状态标记见各域 README 清单表

## 原文获取

openstd.samr.gov.cn → 检索标准号 → 详情页「在线预览/下载标准」
(非采标可下载;下载有会话保护,需浏览器人工操作)。
