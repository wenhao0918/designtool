# 语义→数值映射定义 V0 —— 词表与枚举的对照账

> 版本: V0.1（设计稿）
> 日期: 2026-09-02
> 上位: 《需求矩阵Q定义_V0.md》（§二.5 一词一义/术语块）、《设计指令矩阵表示_V0.md》（§十三 字母表可穷举）
> 任务: 整理**语义面（用户话术）→ 数值面（矩阵枚举与数值）**的完整映射，作为 LLM 词表注入、grammar 校验（8103）、后续 PyTorch/NPU 张量编码的**单一来源**。

---

## 一、三条原则

1. **语义面开放，数值面封闭**：同义词随便说（钢球/滚珠/球），落账只有一种（`sphere`）。开放面允许扩充词条，封闭面枚举一经冻结只追加不改名。
2. **映射是查表，不是理解**：LLM 把用户话对齐到词条（或词条参数），展开成矩阵是确定性查询。LLM 禁止创造数值面不存在的 kind/op/rel/参数键。
3. **每个枚举携带稳定整数 id**：`I∈{0,1}^{N×K}`、`F∈{0,1}^{N×M}` 天然是 one-hot/嵌入索引；id 稳定是 PyTorch/NPU 张量编码与批次对齐的前提。

## 二、体元种类表（I 矩阵的 K 列）

数值面以 FreeCAD Part 原语为准（8 种实体；helix 为曲线体不入实体枚举，PartDesign 同集）。

| id | kind | FreeCAD | 参数(Θ 列) | 语义同义词 |
|----|------|---------|-----------|-----------|
| 0 | `box` | Box | L,W,H | 长方体、方块、块料、立方体（三边全等的判读规则见 §三.4）、方箱 |
| 1 | `cylinder` | Cylinder | r,h | 圆柱、圆柱体、圆棒、棒料、轴段、立柱 |
| 2 | `sphere` | Sphere | r | 球、球体、钢球、滚珠、实心球 |
| 3 | `ellipsoid` | Ellipsoid | r1,r2,r3 | 椭球、椭球体、蛋形体 |
| 4 | `cone` | Cone | r1,r2,h | 圆锥（r2=0）、圆台/锥台（r2>0）、锥形、漏斗体 |
| 5 | `torus` | Torus | r1,r2 | 圆环、环体、圈环、回转环 |
| 6 | `prism` | Prism | n,r,h | 正n棱柱、三棱柱/六棱柱（n=3/6…）、棱柱体 |
| 7 | `wedge` | Wedge | L,W,H | 楔形体、楔块、斜垫、劈形体 |

- "空心球"**不是** kind（历史事故：硬凑 shell_box）——是 `sphere` + shell 算子（§四）或同心球 subtract 术语块（§六）。
- kind 判读含确定规则：box 三边全等仍记 `box`（立方体只是参数特例，不开新 kind）；prism n=4 与 box 按"截面正多边形 vs 矩形"区分，语义含糊时 422 追问。

## 三、参数数值表（Θ 矩阵的取值规则）

### 3.1 词 → 参数键（唯一换算点，全部机械可执行）

| 语义词 | 换算 | 备注 |
|--------|------|------|
| 直径 D / Ø / φ / 直径xx | `r = D/2` | 全表唯一的除法规则 |
| 半径 R / r | `r` | |
| 高/高度/长（柱、棱柱） | `h` | |
| 长/宽/高（盒、楔） | `L/W/H` | 缺省轴序 X/Y/Z |
| 壁厚/厚 | `t` | 只归 shell 算子，禁写体内参数 |
| 外径/内径 | 禁止直接落账 | 外径→外形参数，内径→shell t（t=(外-内)/2），由 Q2 规范化算 |
| 边长a（prism） | `r = a/(2·tan(π/n))` | 外接圆半径换算（Q2 规则，LLM 不算） |
| 环半径/管半径 | `r1/r2` | |
| 锥底径/顶径 | `r1/r2` | "尖"→r2=0 |

### 3.2 单位

缺省 `mm`。识别词：mm/毫米、cm/厘米、m/米、in/英寸。统一换算成 **mm** 后落账（矩阵内部单位恒为 mm，换算在语义层完成）。

### 3.3 数值形态（对齐 §3.2 区间意图）

| 语义 | 落账 |
|------|------|
| 定值："Ø100" | `value=100` |
| 区间/规格："Ø80~120" / "以后可能换" | `interval=[40,60]`（半径域）→ 批量扫描任务 |
| 约数："大约100" | `value=100` + `attrs.confirmed=false`（Q2 待确认，回显时追问） |

### 3.4 必填最小集（对齐 Q 定义 §二.5 规则1）

每 kind 参数分三级：required（box:LWH；cylinder:r,h；sphere:r；cone:r1,h）、optional（cone:r2 缺省0；ellipsoid:r2,r3 缺省=r1）、system（禁止 LLM 写：由换算规则导出的 r、pos、name 编号）。

## 四、算子表（F/T 矩阵的 M 列）

| id | op | 语义同义词 | 参数 |
|----|-----|-----------|------|
| 0 | `fuse` | 融合、合并、并集、拼接、焊成一体 | parts[] |
| 1 | `cut` | 切掉、去掉、开孔、挖槽、钻孔、减去 | base, tool |
| 2 | `common` | 公共部分、交集、重叠部分 | a, b |
| 3 | `shell` | 空心、掏空、薄壁、壳 | t |
| 4 | `fillet` | 圆角、倒圆、倒圆角 | r |
| 5 | `chamfer` | 倒角、斜切边 | c |
| 6 | `pattern_linear` | 均布n个、线性阵列、等距n孔 | n, d |
| 7 | `mirror` | 镜像、对称 | plane |

- "开孔" = `cut` + 圆柱刀具（刀轴/贯穿规则由组合约束保证，LLM 不管几何可达）。
- "空心球" = `shell(t)`，或 §六 术语块展开为同心球 subtract——两法等价，术语块优先（回显更短）。

## 五、方位与旋转（位姿基 6：Tx,Ty,Tz,Rx,Ry,Rz）

### 5.1 轴词 → 轴 id

| 语义 | 轴 | 备注 |
|------|----|------|
| X轴/X向/左右 | x | 工程口语约定，可在 grammar 配置 |
| Y轴/Y向/前后 | y | |
| Z轴/Z向/上下/竖直/铅直 | z | 缺省轴（"旋转90°"未说轴 → 422 追问，不代猜） |

### 5.2 旋转词

角度：`45度/°`、`直角→90`、`半圈→180`、`一圈→360`、`π/4→45`。
方向：右手系逆时针为正；"顺时针→负角"。V1 旋转自由度入矩阵（开放问题#3），V0 旋转词只允许落在单体的 placement 字段。

## 六、术语块（具名子矩阵，§13.3 的落地形态）

语义直译块名 + 块参数，展开为 bodies+features+relations 的**确定性模板**：

| 块名 | 语义词 | 参数 | 展开 |
|------|--------|------|------|
| `hollow_sphere` | 空心球 | D, t | sphere(r=D/2) + shell(t) |
| `through_hole` | 通孔 | d, base | cut(cylinder 刀贯穿) |
| `blind_hole` | 盲孔 | d, h, base | cut(刀不贯穿) + 验证 h<base 深度 |
| `flange` | 法兰盘 | D, d, n, t | 环形板 + n×pattern 孔 |
| `keyway` | 键槽 | w, h, L, base | cut(方块刀) |

新术语 = 新块入库（版本化、可审计），文法/装配器/求解器零改动。

## 七、语义归一化漏斗——知音（Zhiyin）接入

语义面开放 ⇒ 归一化需要一个引擎。**知音**（`DesignTool/Zhiyin`，语义理解层）承担
"用户话 → 标准词条"的四级漏斗，本表只管词条落账后的数值面。

知音的两重价值：
- **准确性**——方言/俗称/行话在语义层收口为标准词条，LLM 不直面开放语义，错译面收窄到词条内（漏斗见下）；
- **个性化**——知音·记 维护用户级偏好：惯用说法（"眼儿"=通孔）、默认材料/精度、常用尺寸档位 → ①同义词匹配时个人词表优先；②Q2 规范化的默认值按人注入（老手不追问、新手多确认）；③用户纠正即时回流个人词表，越用越顺手。个性化只影响**语义面排序与 Q2 缺省**，数值面枚举与 id 恒定——个人习惯不改公共词表。

```
用户话 ──► ① 精确词表(vocabulary.json 同义词, grammar 毫秒级)
        ──► ② 知音 MySQL 术语表(标准术语/结构化映射 mapping.geometry → kind/op/术语块名)
        ──► ③ RAG 向量检索(L1标准/L2俗称方言/L3动词化/L4意图性 四层表达语料)
        ──► ④ 知识图谱消歧(上下文联想: "螺丝不能冒出来"→沉头孔; 多候选→主动反问)
        ──► 全不中: 422 追问 / EVOLUTION 立新词条（永不静默）
```

| 知音能力 | 在翻译链路中的落点 |
|---------|------------------|
| 四层表达匹配（听·辨） | 语义面 → 本表词条的第一道桥：方言/俗称/口语先归一到标准术语 |
| 歧义消解 + 主动反问（听·问） | 产出 `clarifying_questions`，与 422 追问、回显确认同用一套话术 |
| 术语知识库 + 图谱（听·谱） | 词条间父子/等价/互斥关系，支撑"多候选"仲裁；`mapping.geometry` 直连本表 kind/op/块名 |
| 对话上下文 + 偏好记忆（知音·记） | 同会话第二句"再来一个"的指代消解；用户惯用词优先；个性化双落点——语义面（个人词表排序）+ Q2 面（个人缺省值），数值面 id 不动 |
| 降级链 | RAG 不可用 → MySQL 精确匹配 + 词表规则兜底（基本功能不中断） |

接入约束：
1. 知音输出**标准术语上下文 JSON**（terms/mapping/constraints/questions），Anvil LLM 只基于该 JSON 落 ΔQ——LLM 见到的是归一化后的词，不再直面方言。
2. 知音的 `mapping.geometry` 值域 = 本表数值面枚举（kind/op/块名），两表经 `vocabulary.json` 同源，禁止两套清单。
3. 新方言/俗称 = 知音·记 收录 → 词表评审追加同义词（EVOLUTION），数值面 id 不动。

### 7.5 矩阵单元格记法（唯一规范，2026-09-03）

ΔQ/Q 的稀疏单元格，**数据形式**（组件间交换、存储、计算一律用它）：

```json
{"row": 42, "mat": "Θ", "col": "p/r", "val": 50}
```

- `row`：条目指称（单调整数，见 Q 定义 §二 指称与引用）
- `mat`：矩阵组 I(实例)/Θ(参数)/F(算子)/T(算子参数)/R(派生)/S(关系)/B(位姿)
- `col` 规范列名：I→`kind/<kind>`；Θ→`p/<key>`；F→`op/<op>`；T→`op/<op>/<param>`；B→`dof/<自由度>`；R→`derived/<op>`；S→`rel/<谓词>/<对端行>`
- **显示形式**仅展示层使用：`Θ[42,p/r]=50`，由唯一函数 `fmt_cell` 生成
- **唯一实现**：`Anvil/anvil/qledger.py` 的 `sparse_cells()`——其它组件（前端回显、8103 grammar、NPU 装载）一律消费其输出，禁止另造记法

## 八、张量化预留（PyTorch/NPU 对接口）

1. **枚举即索引**：kind id → `I` 矩阵 one-hot 列；op id → `F` 列；k/词表序即 embedding 查表行号。id 稳定 ⇒ 增量训练/推理无需重排。
2. **条目即行号**：条目指称 = 单调整数（永不复用），即 I/Θ/F/S 的行号——Q 整体就是一张行对齐的稀疏矩阵；retired 行掩零保留行位，torch 稀疏张量直接装载；LLM 只交符号，行号由加法器确定性发放（符号→数）。
2. **Θ 稀疏**：每体只填本 kind 的参数列 → `torch.sparse_coo_tensor` 或 masked dense；缺失参数位 = 0 掩码。
3. **合批**：同 kind + 同稀疏模式 + 同 batch_key → 堆叠 `[B,N,P]` 张量，区间扫描 A·X=B(θ) 卸 NPU。
4. **机器可读词表**：本表同步维护 `vocabulary.json`（kind/op/rel/术语块：id、参数 schema、同义词数组、换算规则），8103 `GET /api/grammar` 直接下发，prompt 例句同源生成（规则4，永不脱节）。

## 九、验收与治理

- 词表冻结：新增同义词/术语块走 EVOLUTION 单，附例句；数值面枚举改动 = 破坏性变更需评审。
- LLM 禁写项：kind/op/rel 之外的任何键、system 参数、plan_hint；违者 422 报词条号+建议项。
- 金测试集按本表覆盖率出题（每词条 ≥4 题：直称/换算/单位/同义词），指标沿用一次译过率 ≥90%、往返 ≤1.2。
