## 二、公理体系（The Axiomatic System）

### 2.1 本体论四元组（何为机械？）

> **𝕄 := (𝕋, 𝔾, ℬ, ℱ)**

| 元 | 数学对象 | 工程语义 | 宗法对应 |
| :--- | :--- | :--- | :--- |
| **𝕋（拓扑）** | 胞腔复形（CW Complex） | 零件连接图、运动副类型、约束传递链 | **宗法骨架**——谁主谁从、谁连谁断 |
| **𝔾（几何）** | 嵌入欧氏空间的子流形，带黎曼度量 | 尺寸、形状、公差带、材料分布 | **礼器形制**——尺寸与容差 |
| **ℬ（边界）** | 带标记的流形边界 | 与环境的能量/物质/信息交换界面 | **庙堂之门**——内外之分，通塞之界 |
| **ℱ（功能）** | 能量空间间的可微分映射 | 功率流的可控变压器 | **天命**——定向转换 |

**体化条件**：𝕄 成其为机械，当且仅当 ∃ ℬ ⊂ ∂𝔾，使得 ℬ 为能量/物质/信息交换的定向界面，且 ℱ 通过 ℬ 实现输入-输出映射。

> 刚性体、柔性体、受约束流体可成其体；波与场可充其用，不可为其体。

### 2.2 核心算子（何为约束？）

> **𝒞 = 𝒫 ⊕ ℳ ⊕ 𝒱**

| 约束层 | 形式 | 性质 | 宗法对应 |
| :--- | :--- | :--- | :--- |
| **𝒫（物理场/硬律）** | 等式——守恒律算子 F(x,u,∇u) = 0 | **百世不迁**，违则结构不存在 | 大宗之法 |
| **ℳ（制造场/可行）** | 不等式——可达性函数 gᵢ(x) ≤ 0 | **五世则迁**，随技术代际演化 | 小宗之礼 |
| **𝒱（价值场/偏好）** | 偏序——价值泛函 hⱼ(x) ≤ cⱼ | **可谈判**，但梯度方向由前两层投影决定 | 族长之志 |

**运算规则**：⊕ 是流形上的耦合，非简单叠加。
**存在性判据**：结构存在的充要条件是 **𝕄 ∈ 𝒫 ∩ ℳ**。价值场仅决定“在可行域内向何处收敛”，不决定“是否存在”。

### 2.3 约束势与稳态解

定义约束势：

> **Φ(x) := Φₚ(x) ⊕ Φₘ(x) ⊕ ℛ(x) ⊕ Φᵥ(x)**

其中：

- **Φₚ = λₖ∥Fₖ(x)∥**——拉格朗日乘子项，等式约束，必须精确为零
- **Φₘ = I_{gⱼ>0}·∞ + Σ[gⱼ⁺]²**——硬势垒 + 软惩罚，不等式边界不可逾越
- **ℛ**——资源消耗泛函（温度积分、塑性功、时间），“行礼之费”
- **Φᵥ = [hⱼ(x)/cⱼ]⁺**——价值梯度方向，可谈判但必须存在

**结构𝕄作为稳态解涌现的条件**：

> **∇Φ(𝕄) = 0**

即：结构不是被“搜索”到的，而是在约束势的梯度下降中**自然收敛**的谷底。作用方式是收敛到稳态，而非前向传播。

### 2.4 可达性第一性原理

> **执行优化前，必须先证明：∃ 连续路径 γ(t) ∈ 𝒞，从初始种子收敛至稳态 ∇Φ(𝕄)=0。**

**递归三定律**：

| 定律 | 数学表述 | 工程含义 |
| :--- | :--- | :--- |
| **Base Case** | ∃ n₀, f(n₀) = c（常数，不再递归） | 物质元（弹性模量、液相线）外部给定，不可自举 |
| **Recursive Case** | f(n) = g(f(n-1), n) | 约束传播——从父结构推子结构 |
| **Progress** | \|n − n₀\| 单调减 | 设计熵单调减，向稳态收敛 |

### 2.5 数学适定性（Mathematical Well-posedness）

物理场 `𝒫` 写为**总势能泛函** `Π(u)`。制造约束 `ℳ` 引入为**闭集（指示函数）**。

**判定标准**：证明该变分问题满足 **Lax-Milgram 定理**——
- 解存在（Existence）
- 解唯一（Uniqueness）
- 解连续依赖边界条件（Stability）

这是保证“物理现实”而非“数学幻觉”的底线。

**离散-连续极限**：

> **lim_{h→0} 𝒞ₕ = 𝒞**

只要离散表达满足Lax等价定理（有限元）或通用逼近定理（神经场），离散就不再是障碍，而是通往连续的桥。

## 附录A：基准变分问题——悬臂梁的数学表述

> 本附录为阶段二（数学依据与离散化）的核心输出物。源自Primordium理论框架的首次具体数学落地。

### A.1 问题定义

**几何**：二维矩形域 Ω = (0, L) × (0, H)，左端 Γ_D 固定，右端 Γ_N 受集中力 F。

**材料**：各向同性线弹性，杨氏模量 E，泊松比 ν。

**目标**：寻找位移场 u(x) 与密度场 ρ(x)，使结构柔度最小，同时满足体积分数约束与物理方程。

### A.2 总势能泛函

**连续形式**：

> **Π(u, ρ) = ∫_Ω ρᵖ · ½ ε(u)ᵀ D₀ ε(u) dΩ − ∫_{Γ_N} F·u dΓ**
>
> **s.t.** ∫_Ω ρ dΩ ≤ V_f · Vol(Ω)，0 ≤ ρ ≤ 1

其中：

- ρ ∈ [0,1] 是密度场（设计变量，ρ=1 有材料，ρ=0 无材料）
- p ≥ 1 是SIMP惩罚指数（通常 p=3）
- ε(u) = ½(∇u + ∇uᵀ) 是小应变张量
- D₀ 是固体材料的弹性本构矩阵

### A.3 物理场 `𝒫` 的表述

变分问题的一阶最优性条件（Euler-Lagrange方程）给出：

> **平衡方程**：−∇·(ρᵖ D₀ ε(u)) = 0，在 Ω 内
> **边界条件**：u = 0 在 Γ_D 上；n·σ = F 在 Γ_N 上

这正是线弹性力学的**控制方程**——`𝒫` 场的等式约束。

### A.4 制造场 `ℳ` 的表述

制造约束以不等式形式嵌入：

| 约束类型 | 数学形式 | 工程含义 |
| :--- | :--- | :--- |
| 体积分数 | ∫Ω ρ dΩ ≤ V_f·Vol(Ω) | 材料用量上限（铸造/锻造经济性） |
| 密度边界 | 0 ≤ ρ ≤ 1 | 物理可实现性 |
| 最小成员尺寸 | 通过滤波/投影算子隐式实现 | 避免棋盘格与制造不可达的细碎结构 |
| 拔模/加工约束（后期） | 通过额外线性不等式添加 | 后续扩展 |

### A.5 价值场 `𝒱` 的表述

目标函数本身即为价值场：

> **minimize C(u, ρ) = ∫_Ω ρᵖ · ½ ε(u)ᵀ D₀ ε(u) dΩ**

等价于最小化**结构柔度**（最大化刚度）。

### A.6 适定性分析（Lax-Milgram）

对于固定 ρ，定义双线性形式：

> **a(u, v) = ∫_Ω ρᵖ ε(u)ᵀ D₀ ε(v) dΩ**
> **l(v) = ∫_{Γ_N} F·v dΓ**

**判定**：

1. **连续性**：∃ M > 0, |a(u,v)| ≤ M∥u∥₁∥v∥₁ ——由材料张量有界性保证
2. **强制性**：∃ α > 0, a(u,u) ≥ α∥u∥₁² ——由 ρᵖ ≥ 0（ρ∈[0,1]）且弹性张量正定保证

因此，对任意给定的 ρ ∈ [0,1] 且 ∫ρ ≤ V_f，**位移场 u 存在、唯一、连续依赖载荷 F**——`𝒫` 场是良定义的。

### A.7 离散化格式（准备接入CANN）

采用**有限元（FEM）**离散：

1. 将 Ω 划分为 N 个单元（四边形/三角形网格）
2. 每个单元内位移用形函数插值：uₑ(x) = Nₑ(x)·dₑ
3. 单元刚度矩阵：kₑ = ρₑᵖ · ∫_Ωₑ Bₑᵀ D₀ Bₑ dΩ
4. 全局组装：**K(ρ)·d = F**

其中 K(ρ) 是稀疏对称正定矩阵（规模 N_dof × N_dof，N_dof 通常数万至数百万）。

**迭代格式**（OC/MMA）：

> **给定 ρ⁽⁰⁾ → 求解 K(ρ)u = F → 计算柔度 C = Fᵀu → 更新 ρ 以满足体积约束 → 重复直至收敛**

### A.8 与CANN的接口准备

| 连续形式 | 离散后 | CANN接口 |
| :--- | :--- | :--- |
| 弹性本构 D₀ | 单元刚度矩阵 kₑ | Ascend C 自定义核（支持不同本构） |
| 总刚度矩阵 K(ρ) | 稀疏矩阵 `[K]` | `aclnnSparseMatMul` |
| 载荷向量 F | 稠密向量 `{F}` | `aclnnMatMul` / 直接搬运 |
| 线性求解 K u = F | 共轭梯度法（CG） | 自定义CG循环，每步调用 `aclnnSparseMatMul` |
| 灵敏度分析 dC/dρ | 矩阵-向量乘 | `aclnnMatMul` |
