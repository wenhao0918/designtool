## 一、立场

设计指令不再是"给 LLM 的一句话"，也不是"给脚本的 JSON"——它是**一个数学对象**。

指令矩阵化之后，设计获得四种新性质：

| 性质 | 含义 |
|---|---|
| **可解** | 位姿/参数不是猜的，是线性代数解出来的 |
| **可诊断** | 欠定/过定/冲突/自由度——全部是秩与零空间，可判定并报告 |
| **可追溯** | 每个矩阵元素携带来源指令号——符合"执行必须可追溯至硬约束公理" |
| **可演化** | 设计修改=矩阵微分（改一个元素/加一行）；批量探索=同稀疏模式批量求解（NPU 甜点） |

检验一句 OLD 话：**设计的自由度 = 约束矩阵的零空间**。设计过程 = 零空间的受控收缩。

## 三、几何块（V0 正式化）

### 3.1 六张矩阵

```
I ∈ {0,1}^{N×K}     实例: I[i,k]=1 ⟺ 体 i 是第 k 种体元（球/柱/盒…）
Θ ∈ ℝ^{N×P} 稀疏     形状参数: Θ[球,r]=50（每体只填自己种类的列）
F ∈ {0,1}^{N×M}     算子关联: F[i,shell]=1 ⟺ 体 i 施加壳算子
T ∈ ℝ^{N×M×·}       算子参数: T[i,shell,t]=20
S ∈ {0,1}^{C×N}     关系超图: S[j,a]=S[j,b]=1 ⟺ 关系 j 连接体 a,b
τ ∈ ℕ^C, π ∈ ℝ^{C×q} 关系类型与参数: τ[j]=rests_on_centered
B ∈ {0,1,*}^{D}     边界锚定: D=3N 个平移自由度, B 覆盖的自由度=钉死
```

### 3.2 装配与求解（FEM 同构）

每种关系谓词 = 一个**单元方程模板**（局部系数 + 局部右端），经散射矩阵 Lⱼ 装配：

```
A = Σⱼ Lⱼᵀ Aⱼᶜ(τⱼ, πⱼ) Lⱼ  ∈ ℝ^{D×D} 稀疏
b = Σⱼ Lⱼᵀ bⱼ
求解: B 掩码下解 A x = b（scipy spsolve；超定→稀疏最小二乘）
诊断: 零空间 N(A) —— 每个基向量对应一组未定自由度，按体名报告
```

**新关系谓词 = 一个方程模板（十几行代码），装配器与求解器零改动。**

### 3.3 三种可判定状态

| 状态 | 判据 | 报告 |
|---|---|---|
| 适定 | rank(A)=D | 解唯一，输出位姿 |
| 欠设计 | dim N(A)>0 | "底板 X 向未定（1 自由度）"——交用户决策，**禁止代猜** |
| 过约束 | b∉列空间（最小二乘残差≠0） | 报出互相冲突的关系行号 |

## 四、物理块（V2，先"单位验证器"后"场"）

```
M̂ ∈ ℝ^{N×m}   材料矩阵: M̂[板, σy]=235（Q235 屈服 MPa）, M̂[板, E], M̂[板, ρ]…
L ∈ ℝ^{N×6}   载荷矩阵: 每体承受的广义力 [Fx,Fy,Fz,Mx,My,Mz] + 作用点
E ∈ ℝ^{e×2}   工况包络: [温度区间, 载荷循环数, 介质…]（区间,非单值）
```

**验证不走完整 FEM 起步**——按角色挂**闭式工程验证器**（机械设计手册公式）：
角色模板 R[i]=bearing_seat → 自动装配"额定载荷/压强校核"方程；σ ≤ σ_y(M̂) ∩ E。
输出仍只有 PASS / VIOLATION（𝒫 层禁概率）。
完整场离散化（K·u=f，共轭梯度卸载 NPU）= 上位文档 V3，不在本版。

## 五、运动块（V1.5，机构=零空间工程）

```
J ∈ {0,1}^{Cⱼ×6}   运动副授权矩阵: J[铰1, Rz]=1 ⟺ 该副允许绕 Z 相对转动
```

关键洞察：**约束行移除相对自由度，运动副行授回特定相对自由度——同一本账**。

```
机构自由度 M = dim N(A_全系统)    （Kutzbach 的矩阵化）
"设计一个能翻转 90° 的机构" = 工程化零空间: 允许 Rz 方向留在零空间,其余全部约束掉
```

装配体是 M=0 的特例。运动需求（转角范围/行程）= 零空间方向上的区间约束。

## 六、制造块（𝒞ₘ，V1）

```
Cₘ ∈ 不等式组   每体: 壁厚≥工艺极限, 深径比≤极限, 圆角r≥刀具r, 拔模角≥…
```

## 七、意图块（本稿核心构思——意图的三个数学工具）

"意图"不是注释，是三种可操作的数学对象：

### 7.1 固义（fixity）——"必须永远成立"
→ **加约束行**。零空间收缩一维。
例："孔必须对轴心" → coaxial 行。之后任何编辑若再想消掉它，只是正常加行，无特殊处理。

### 7.2 调义（adjustability）——"保留这个自由"
→ **保护一个零空间方向 v**。"安装孔位留调节量" = 平移某方向必须留在 N(A) 内。

**意图漂移检测（可判定）**：每次编辑后算 vᵀ 投影——若 v ∉ N(A_new)，
报 `INTENT_LOST: '安装孔调节量' 在第 7 次修改后被约束吞掉`。
这给"设计意图被后续修改冲掉"这个千古痛点一个精确的数学定义与检测器。

### 7.3 权衡（tradeoff）——"这两个目标怎么舍"
→ **𝒞ᵥ 层权重向量 w**（成本/美学/寿命）。只允许作用于 𝒞ᵥ 层；
**禁止反哺覆盖 𝒫/𝒞ₘ 判定**（上位文档铁律 2 的矩阵化表述）。

### 7.4 形状意图（参数区间）
"球可换 Ø80~Ø120 规格" → Θ 区间列 Θ̃：验证 A x = b(θ) 对 ∀θ∈box 可解
（线性系统=区间端点验证）。参数化设计的"改规格不出错"由此保证。

## 八、组织与溯源

```
G ∈ {0,1}^{N×G}   装配分组: 体×模块（底座组/球组/…）

```

Φsrc 使"这个孔是哪句指令带来的"永远可回答；删除指令=按 Φsrc 逆删矩阵行。

## 九、统一未知向量与分块求解

```
𝕏 = [ X位姿(3N) | P待定参数(Θ̂) | U场量(V3) ]
     └──几何块解──┘  └参数反求─┘   └物理块解┘

流水线: 句子 → 五张几何矩阵 → 装配 A,x=b → 适定诊断 → 位姿
        → CSG 代数层(形状) → 𝒞ₘ 不等式 → 物理单位验证器(V2) → STEP
映射:   稀疏装配/秩诊断=CPU；批量参数扫描/场迭代=NPU(V2+,对齐上位文档分工表)
```

LLM 边界不变：**句子 ↔ 矩阵是文法强制的双射**。LLM 写句子，翻译器灌矩阵；
LLM 不碰矩阵，矩阵不需要懂语言。意图三工具同样由句子携带（文法 V1 扩词条）。

## 十、全维示例（空心球底座 × 三条指令）

**指令①（几何）**："空心球 Ø100 壁厚20，下置 100×100×20 平板底座，球置于底座中心"
**指令②（物理）**："底座要承受 500kg 静载"
**指令③（意图）**："球规格以后可能换 Ø80~120"

```
I  = [球:sphere; 板:box]
Θ  = Θ[球,r]=50  Θ[板,L]=100 Θ[板,W]=100 Θ[板,H]=20
F  = F[球,shell]=1   T[球,shell,t]=20
S  = S[贴合1,球]=S[贴合1,板]=1    τ=rests_on_centered
B  = [x板,y板,z板] 钉死
A x = b → x球=(0,0,70)      ← rank 6/6, 适定
CSG: 材料 = 球(50) ∖ 球(30)  ← 30=50−20 减出来的
Cₘ: t=20 < r=50 → PASS
物理(V2): σ = 500·g / (100·100) ≈ 0.49 MPa ≪ σy=235 → PASS（单位验证器）
意图(③): Θ̃[球,r]∈[40,60] → 区间端点重解 A x=b(θ): z球∈[60,80] 全程贴合 → 区间可行 PASS
```

三条指令，三个维度，各走各的矩阵，汇入同一次构建。

## 十三、字母表总表——可穷举词汇的矩阵化（定调）

基本几何形状（建模用）、位移、旋转等基本可穷举；设计意图、工艺、设计术语同样可用矩阵表述。
可穷举 = 文法封闭。设计语言是**有限字母表上的形式语言**，矩阵是它的语义载体；
组合无限出自字母有限。

### 13.1 基础字母（枚举闭集，每族一列/一行模式）

| 词汇族 | 基数 | 矩阵载体 |
|---|---|---|
| 体元种类 | K（球/柱/盒/锥/环…） | I 的列 |
| 特征算子 | M（壳/阵列/圆角/镜像…） | F 的列 |
| 关系谓词 | R_rel（贴合/居中/同轴/间距/共面…） | τ 的值域 |
| 位姿基 | 6（Tx,Ty,Tz,Rx,Ry,Rz） | 未知向量分块 |
| 运动副类型 | 相对 6 DOF 的常用子集：转动{Rz}/滑动{Tz}/球铰{Rx,Ry,Rz}/刚性{}… | J 的行模式 |
| 意图类型 | 4（固义/调义/权衡/区间） | 意图矩阵行类型 |
| 工艺类型 | CNC/打印/车削/钣金/铸造… | Cₘ 分组维度 |

> 落地清单：体元 K/算子 M/谓词 R_rel 的**逐项枚举、参数 schema、同义词与换算规则**见《语义数值映射定义_V0.md》——数值面单一来源，vocabulary.json 同源下发 grammar 与知音（§七 四级漏斗），语义面开放由知音收口，数值面 id 恒定（张量编码前提）。

### 13.2 位移与旋转：同一本 6 维自由度账簿的三种操作

每体 6 DOF，每体对 6 个相对自由度。全部"关系类"词汇只是这本账簿上的三种动作：

```
约束行 = 消去某方向        （贴合消 Tz、同轴消 Tx,Ty）
运动副 = 授回某方向        （铰链授回 Rz）
意图锁 = 保护某方向不被后续消去 （调义）
```

机构的可动性、装配的刚性、意图的保留——全部化为对同一账簿的加减锁，
可判定（秩与零空间）、可报告（哪些方向留了/没了）。

### 13.3 设计术语 = 具名块（行话丰富，内核极小）

"盲孔/沉孔/退刀槽/键槽/法兰盘/加强筋…"——设计术语不是文法外的自由语，
而是**参数化的具名子矩阵块**（预定义的 bodies+features+relations 组合模板）：

```
术语库条目:  盲孔(直径 d, 深度 h, 基体 base) → [side_hole 块, through=false]
             法兰盘(D, d, n, t)              → [环形板块 + n 孔 pattern 块]
```

- LLM 可以说行话（用户原话直译），展开为矩阵块是**确定性的词典查询**
- 术语库 = mech_terms/GbstdService 既有底座的矩阵化升级，版本化、可审计
- 新术语 = 新块入库；**文法、装配器、求解器零改动**

这就是"用户语言丰富度"与"内核最小性"的解耦通路：内核字母表保持 K+M+R_rel+6 极小，
术语层无限扩充，每层各司其职。
